# v0.7.6: rooms without a Hermes endpoint, installer fixes

Release notes body for the `v0.7.6` GitHub release. The full per-change text lives in
[`CHANGELOG.md`](../../CHANGELOG.md) under `## 0.7.6`; this file is the operator-facing summary.

## What is new

- **Rooms on a gateway with no Hermes endpoint** (`com.cozylabs.bots` capabilities 46 and 52,
  #380). A gateway with zero `hermesEndpoints` entries now owns its rooms end to end: create,
  list, detail, member turns on the gateway-owned `group:<room>:<member>` thread, room-scoped
  Tasks, room approvals, and delete. Bridge selection on a gateway that has a Hermes endpoint is
  untouched. The contract now states exactly which gateway shapes host a room: two or more
  endpoints, or a single `namespace: true` endpoint, still refuse every room with 503.
- **Installer and provisioner scripts no longer require host PyYAML to read a profile's streaming
  keys** (#381). One reader with two modes is shared verbatim by `scripts/agent-install.sh`,
  `scripts/provision-bot.sh`, and `scripts/bot-provisioner-watch.sh`: PyYAML when the interpreter
  has it, Hermes' own venv python tried first; otherwise a conservative stdlib probe that writes
  nothing and restarts nothing whenever it cannot judge a key with certainty. `scripts/install.sh`
  bootstrap now recognizes Git Bash as the `Windows` service platform instead of dying on an
  unsupported platform.

## Upgrading

This tag is additive: no schema change and no config change. Existing installs upgrade by
rerunning the published installer. Windows installs through Git Bash now bootstrap correctly,
where they previously failed on an unsupported service platform.

## Verification

Hosted CI on this tag (`.github/workflows/release.yml`) runs `pnpm check`, `pnpm test:installer`,
verifies the tag version matches `packages/gateway/package.json` and
`integrations/attach-plugin/plugin.yaml`, builds the release bundle with `pnpm bundle`, attests the
built artifacts, and smoke-tests the bundled gateway binary against `GET /health` before publishing
the GitHub release.
