# v0.9.2: CozyGateway is the Hermes connector

Release notes body for the `v0.9.2` GitHub release. The full per-change text lives in
[`CHANGELOG.md`](../../CHANGELOG.md) under `## 0.9.2`; this file is the operator-facing summary.

## What changed for you

CozyGateway is now the connector for Hermes. If you run CozyAgents, use CozyAgents' built-in
gateway instead; this one no longer carries any CozyAgents code. Nothing changes for Hermes bots,
Hermes chats or paired computers. They keep working as they did.

This release removes dead code and stale docs (ADR 0087). It adds no features.

## Removed

- The bot history routes. They now return 404. Nothing in Hermes chats used them.
- CozyAgents bot creation. It was already refused in earlier releases, and the code behind the
  refusal's old path is gone.

Every database table and column stays. A database from an older gateway still opens. If it holds
leftover CozyAgents rows, startup logs one line with their counts. Nothing is deleted.

## Upgrading

1. Back up the gateway database, and your Hermes profiles and bot workspaces. A software rollback
   is not a backup.
2. Run `cozygateway repair` (`cozygateway update` is an alias). Profiles, pairing and model
   settings are kept.
3. Check that `/health` reports version 0.9.2.
4. Open CozyChat and check that Computers still lists your paired computers.
5. Check that your Hermes profiles show as online.

## Rolling back

Restore the previous bundle. You do not need to restore the database: no table or column changed,
and 0.9.1 reopens a database that this build has used.

## Also in this release

- A Windows test for local TLS status has a longer timeout (#17).
- Dependencies: vitest 5.0.3, @types/node 26.6.4, hono 4.13.13 and @arethetypeswrong/cli 0.18.5.

## Verification

Hosted CI on this tag (`.github/workflows/release.yml`) runs `pnpm check`, `pnpm test:installer`,
verifies the tag version matches `packages/gateway/package.json` and
`integrations/attach-plugin/plugin.yaml`, builds and attests the release bundle, and smoke-tests
the bundled gateway against `GET /health` before publishing.
