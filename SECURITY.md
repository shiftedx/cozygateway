# Security policy

Report a suspected vulnerability privately through GitHub's security advisory flow for this
repository. Include a minimal reproduction, affected version, and impact. Do not include tokens,
pairing codes, private keys, or user message content in the report.

We support the current release line. We will acknowledge reports, investigate them privately, and
coordinate a fix and disclosure when there is a confirmed issue.

For non-security questions, use [GitHub Discussions](https://github.com/shiftedx/cozygateway/discussions).
